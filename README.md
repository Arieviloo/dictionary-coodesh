# Mobile Challenge - Free Dictionary App

> Este é um desafio técnico para avaliar habilidades como Mobile Developer, consumindo a Free Dictionary API para listagem, consulta e gerenciamento de vocabulário em inglês.

This is a challenge by Coodesh.

## 🚀 Tecnologias Utilizadas

- **Framework:** React Native (Expo) com TypeScript
- **Estilização:** StyleSheet / Componentes sob medida
- **Gerenciamento de Estado & Cache:** Zustand & TanStack Query (React Query)
- **Persistência Local:** React Native MMKV
- **Testes:** Jest & React Native Testing Library (Diferencial 3)
- **Autenticação & Backend:** Firebase Auth / Firestore (Diferencial 4)
- **Injeção de Dependência:** Design Patterns com Repositórios Abstratos (Diferencial 2)
- **Multimídia:** Expo AV para Reprodução de Áudio Fonético (Diferencial 1)
